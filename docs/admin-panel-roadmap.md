# نقشهٔ توسعهٔ پنل مدیریت

## نیازهای استخراج‌شده از صفحات فعلی

| صفحه | نیازهای مدیریتی |
| --- | --- |
| صفحهٔ اصلی | اطلاعیه، متن‌ها و تصاویر هیرو، کارت‌های خدمات، آدرس و شبکه‌های اجتماعی |
| سالن مطالعه | تنظیمات هیرو، تعرفه‌ها و اینترنت، قوانین، اطلاعات تماس و بررسی درخواست‌های عضویت |
| خدمات تحصیلی | تنظیمات هیرو و راه‌های تماس، تعریف خدمات و زمان‌های مشاوره، بررسی درخواست‌های مشاوره |
| بورسیه‌های فعال | ایجاد، ویرایش، انتشار/بایگانی و حذف بورسیه؛ منبع، مهلت، شرایط، مدارک و تاریخ آخرین بررسی |
| دستاوردها | تأیید یا رد دستاوردهای ارسالی، مدیریت آمار و محتوای تالار افتخارات |
| دربارهٔ ما | متن‌های سازمانی، اعضای تیم، اطلاعات تماس و بررسی درخواست همکاری سازمانی |

## مراحل اجرا

1. **مرحلهٔ اول — صندوق درخواست‌ها:** API پایدار برای درخواست سالن و مشاوره، ورود مدیر با `ADMIN_PASSWORD`، و تأیید یا رد درخواست‌ها.
2. **مرحلهٔ دوم — مدیریت محتوا:** ذخیره‌سازی تنظیمات عمومی، سالن، خدمات و دستاوردها و نمایش دادهٔ ذخیره‌شده در همهٔ صفحات عمومی.
3. **مرحلهٔ سوم — مدیریت بورسیه:** مدل کامل بورسیه، وضعیت انتشار، اعتبارسنجی تاریخ/منبع و جست‌وجو و فیلتر در پنل.
4. **مرحلهٔ چهارم — عملیات و امنیت:** نقش‌ها و کاربران، ثبت رویدادها، بارگذاری رسانه، اعلان، پشتیبان‌گیری و انتقال از فایل محلی به پایگاه‌داده.

## معیار پذیرش مرحلهٔ اول

- درخواست‌های سالن و مشاوره پس از ارسال مرورگر باقی می‌مانند.
- مشاهده و تغییر وضعیت درخواست فقط با نشست معتبر مدیر ممکن است.
- درخواست تأیید یا ردشده از صف «در انتظار» خارج می‌شود.
